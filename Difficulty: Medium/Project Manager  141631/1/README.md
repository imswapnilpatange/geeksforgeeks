<h2><a href="https://www.geeksforgeeks.org/problems/project-manager--141631/1">Project Manager  141631/1</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p class="PDq2pG_selectionAnchorContainer" data-end="290" data-start="125"><span style="font-size: 18.6667px;">An IT company is working on a large project consisting of <strong>n</strong> modules. The time required (in months) to complete the <strong>i<sup>th</sup></strong> module is stored in the array <strong>duration[]</strong>. The array <strong>dependencies[][]</strong>, where dependencies[i] = [u, v], indicates that module v can be started only after module u is completed. Multiple modules can be worked on simultaneously as long as all their dependencies have been completed. Find the minimum time required to complete the entire project. If the project cannot be completed due to a cyclic dependency, return -1.</span></p>
<p class="PDq2pG_selectionAnchorContainer" data-end="290" data-start="125"><span style="font-size: 18.6667px;"><strong>Note:</strong> A module is never dependent on itself.</span></p>

<strong>Output:</strong> 80
<strong>Explanation: </strong>
</span><img height="176" src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/706082/Web/Other/blobid0_1745301599.jpg" width="260"/><br/><span style="font-size: 18px;">The Graph of dependency forms this and the project will be completed when Module 1 is completed. <pre><span style="font-size: 18px;"><strong>Input: </strong>duration[] = [5, 5, 5], dependencies[][] = [[0, 1], [1, 2], [2, 0]]
